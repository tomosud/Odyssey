# 対象範囲と全体像

## 基準構成

- UE 5.8 source: `C:\work\unreal\UnrealEngine-release`
- Desktop Deferred Renderer
- Substrate有効
- Movable Light
- GIはLumenまたは無効、無効時はSkyLightを考慮
- SceneColor既定`PF_FloatRGBA`
- HDR章は主にWindows／D3D12の確認結果

Forward Renderer、Mobile、Path Tracer、Movie Render Queue、platform固有RHIは同じ結論を自動適用しない。

## Rendererを理解する3層

| 層 | 問い | 代表resource／処理 |
|---|---|---|
| Scene-referred rendering | シーン内でどれだけの光が表面へ届き、どう反応するか | GBuffer、Substrate BSDF、Direct／Indirect Lighting、SceneColor |
| View adaptation | cameraとしてどの明るさへ適応するか | Eye Adaptation、Local Exposure、PreExposure |
| Display rendering | displayの輝度・色域・encodingへどう変換するか | ACES Output Transform、PQ、scRGB、HDR UI composite |

## 分離すべき概念

- Shading Model／Substrate BSDF: Materialの光学応答
- Lighting Method: Deferred、Forward、TLV、Lumen等の計算法
- Exposure: scene値を観察するcamera倍率
- Tonemap／Output Transform: scene-referred値をdisplay-referred値へ変換
- Transfer Function: sRGB、PQ等の信号encoding
- Blend Mode: foregroundと既存SceneColorの合成規則

これらを一つの「トーンマップ」または「シェーディングモデル」と呼ばないことが重要である。
