# 設定・診断・既知の不明点

## 主要CVar

| CVar | 既定 | 用途 |
|---|---:|---|
| `r.SceneColorFormat` | platform/config依存 | SceneColor format |
| `r.EyeAdaptation.PreExposureOverride` | - | PreExposure override |
| `r.TranslucencyLightingVolume.Dim` | 64 | TLV解像度 |
| `r.TranslucencyLightingVolume.InnerDistance` | 1500 | TLV inner距離 |
| `r.TranslucencyLightingVolume.OuterDistance` | 5000 | TLV outer距離 |
| `r.VolumetricFog.GridPixelSize` | 16 | fog XY froxel幅 |
| `r.VolumetricFog.GridSizeZ` | 64 | fog Z slice数 |
| `r.HDR.Aces.Version` | 実装初期値2 | 1=ACES 1.3、2=ACES 2.0 |
| `r.HDR.Aces.SceneColorMultiplier` | 1.5 | Standard ACES scene倍率 |
| `r.HDR.PaperWhite` | 203 | HDR reference white |
| `r.HDR.UI.Luminance.Mode` | 0 | UIをPaper White連動／独立 |

## 可視化と診断

- TLV: `r.TranslucencyLightingVolume.Visualize`
- TLV cascade: `r.TranslucencyLightingVolume.VisualizeCascadeIndex`
- GPU Visualizer／RenderDocでpassとresourceを確認
- HDR display切替時はswap-chain formatとcolor spaceを確認
- `r.HDR.Display.*`とGameUserSettingsの実値を記録
- Auto Exposure検証ではPreExposure、Eye Adaptation値、camera cutを同時に記録

## ソースだけでは断定しない項目

- 各console、RHI、driverでの実際のHDR出力挙動
- TV内部のtone mapping、dynamic contrast、game mode処理
- `r.HDR.Aces.Version`のhelp textと初期値の矛盾が意図的か更新漏れか
- 5.7以前との変更時期（比較sourceなしの場合）
- subjectiveな画質優劣

これらは「不明」または「実機確認が必要」と記録し、推測で仕様へ昇格させない。
