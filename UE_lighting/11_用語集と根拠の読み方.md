# 用語集と根拠の読み方

| 用語 | 意味 |
|---|---|
| Scene-referred | displayではなくscene内の相対的な光を基準にした値 |
| Display-referred | displayのnit、gamut、signal encodingへ対応した値 |
| SceneColor | Tonemap前のlinear HDR中間画像。通常PreExposure済み |
| PreExposure | SceneColorの数値範囲を安定させる前倒し倍率 |
| Exposure | cameraとしてscene brightnessへ掛ける倍率 |
| BSDF | 入射光に対する反射・透過・散乱応答 |
| Closure | SubstrateでLighting評価可能な散乱応答単位 |
| GBuffer | Deferred Lighting用のsurface属性buffer群 |
| TLV | Lit Translucency向けの低解像度3D lighting cache |
| Froxel | frustumに沿ったvolume cell |
| Extinction | 吸収＋out-scatteringによる光の減衰係数 |
| In-scattering | 視線方向へ新たに入ってくる散乱光 |
| SH | 低周波方向関数の近似表現 |
| Tonemap | 広いscene dynamic rangeをdisplay条件へ写像する処理 |
| ACES 2.0 | UEでは選択可能なOutput Transform version |
| PQ/ST 2084 | absolute luminanceをHDR信号値へ符号化するtransfer function |
| scRGB | linear FP16を用いるWindows系HDR表現 |
| Paper White | HDR上のreference white輝度 |

## 根拠表記

仕様の根拠は次の優先順位で扱う。

1. 対象versionのEngine／Shader source
2. 対象versionの公式document
3. platform holder／標準規格の一次資料
4. sample project
5. 外部記事・会話メモ

外部記事は調査開始点として利用できるが、sourceと一致した内容だけを仕様本文へ昇格する。詳細な調査履歴は[[90_調査資料/00_調査資料について]]を参照。
